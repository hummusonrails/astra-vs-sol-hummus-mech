# Security reports

Do not post credentials, personal paths or account records in an issue. If private vulnerability reporting is enabled on the repository, use the Security tab. Otherwise open a minimal issue asking for a private reporting route before sharing sensitive details.

The apps publish static files. Local helper servers bind to loopback and are not intended as public production servers. No hosting credential or map API key belongs in the repository. The public benchmark contains aggregate results rather than raw agent sessions.

The privacy scanner helps catch common credentials, home paths and private artifacts. Review source, screenshots and Git author metadata before publishing; a pattern scanner cannot establish anonymity on its own.
