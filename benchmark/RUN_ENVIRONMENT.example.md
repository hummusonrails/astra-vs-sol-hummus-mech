# Run environment template

Workspace: the isolated directory selected for this run. Edit only that directory. Do not inspect another model’s result or unrelated repositories.

Deadline: 600 seconds from initial prompt submission. Install, research, build, browser verification, deployment and handoff all count. Finish early enough to close the session and capture complete usage.

Toolchains: record the installed Node, npm and Python versions before starting. Specify the same tools and browser capabilities for both models. No renderer or framework is prescribed.

Dependencies: begin with equivalent empty or identically prepared package caches. Do not let the second run inherit the first run’s downloads.

Deployment: name a preprovisioned scoped destination and allowed deployment command here. Supply authentication outside the prompt and repository. Verify equivalent access before either scored run. Never print credentials or modify account-wide settings.

Browser: describe the installed Playwright/Chromium setup here. Do not hardcode a personal home directory into source. Use the same viewport, pixel ratio and test route for both models.

Accounting: collect exact final cumulative native-session usage and completed-turn evidence outside the public source tree. Preserve input, cached input, output and reasoning counts without double-counting. A missing complete usage record is not an accepted scored result.

Restrictions: no subagents or external coding models, no paid assets or new accounts, and no human correction prompt during a scored run.
