The original map queries are documented in [the data notes](docs/data.md). Editor usernames, user IDs, edit timestamps, change-set IDs and unrelated contact tags have been removed from the published XML extracts. Geometry, source feature IDs and rendering-relevant tags remain. This publication transformation does not change the displayed street or footprint geometry.

The derived geographic databases remain available in this source repository and are offered under ODbL 1.0, not MIT. Preserve the in-game map credits and database/license links when publishing either app. MIT applies to the original software; it does not relicense third-party data.

Model names describe the build comparison. This is an independent project and is not an official model benchmark or an endorsed OpenAI product.
